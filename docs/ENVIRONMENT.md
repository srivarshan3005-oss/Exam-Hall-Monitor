# Environment variables

Set in `backend/.env` (created by `install.bat` / `python -m app.cli init-env`) or in the process environment. `.env` is never
served and is git-ignored. **Never put credentials in the repository or in `.env.example`.**

| Variable | Default | Purpose |
|---|---|---|
| `SECRET_KEY` | generated by `init-env` | signing key; required, 32+ chars; `python -m app.cli gen-secret` |
| `ENVIRONMENT` | `development` | `production` enforces stricter checks (real SMTP, no demo seed, secure cookies) |
| `DATABASE_URL` | `sqlite:///./exam_monitor.db` | SQLite (default) or PostgreSQL (`postgresql+psycopg://...`) |
| `DOCUMENT_STORAGE_DIR` | `./uploads` | private PDF store and `page_cache/` (never served statically) |
| `BACKUP_DIR` / `LOG_DIR` | `./backups` / `./logs` | backups and logs |
| `COLLEGE_NAME` | `V.S.B. Engineering College, Karur` | display name |
| `VSB_AUTO_DISCOVER_ENABLED` | `true` | automatic scans (scheduler) |
| `VSB_POLL_MINUTES` | `5` | scan interval, clamped to 5-1440 |
| `VSB_SCAN_ON_STARTUP` | `true` | first cycle after start always scans |
| `VSB_EXTRA_PAGES` | `https://coe.vsbec.edu.in/` | extra official listing pages (allow-listed hosts only) |
| `VSB_WP_DISCOVERY` / `VSB_SITEMAP_DISCOVERY` | `true` | WordPress REST / sitemap discovery |
| `VSB_MAX_DOWNLOAD_MB` | `40` | per-PDF size limit |
| `VSB_REQUEST_DELAY_SECONDS`, `VSB_MAX_RETRIES` | see `.env.example` | politeness and retry limits |
| `PUBLIC_PAGE_DPI` | `130` | page-image resolution (72-220) |
| `PREVIEW_CACHE_VERSION` | `v2-unmasked` | change to invalidate every cached page image |
| `SESSION_TIMES` | *(empty)* | e.g. `FN=09:30-12:30,AN=13:30-16:30`; shown only when you set it (not printed in the PDFs) |
| `NOTIFY_WATCH_ENABLED` | `true` | register-number e-mail watch list |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM`, `SMTP_SECURITY` | empty | e-mail; unset = not configured (development uses a local outbox folder) |
| `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `SUPABASE_TABLE` | empty / `live_allotments` | optional mirror (backend only) |
| `CORS_ORIGINS`, `PUBLIC_BASE_URL`, `TRUST_PROXY`, `ENABLE_DOCS` | see `docs/CONFIGURATION.md` | deployment |

Full list and legacy settings: `docs/CONFIGURATION.md`, `backend/.env.example`.
