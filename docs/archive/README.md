# Archive - history of earlier releases

These files describe how earlier releases (V1 - V6) were built and tested. They are kept for traceability only and are **not
current**: statements in them about masking other students' register numbers on page previews, hours-based polling, or
administrator-gated publishing describe the V6 behaviour that **V7 replaced** (see `docs/V7_RELEASE_REPORT.md`).
