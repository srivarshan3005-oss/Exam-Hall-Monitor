# Student guide

1. Open the student portal supplied by the institution. You can use the register-number search without signing in, or sign in (after registering and activating your account) to see **My exams & seats**, **My results** and announcements.
2. Enter your register number and choose Search.
3. Review only published examination and seat information. When a verified hall directory entry exists, the portal also displays building, block, floor and room details. If a record is missing, confirm the register number and contact the examination office; do not assume an unpublished allocation exists.
4. Use the published timetable and current announcements panels for schedule and notice information.
5. If an approved PDF reference is returned, note the original page number. The current release returns the page reference but does not embed a public PDF viewer.
6. Results remain protected and may require a linked student login unless the administrator deliberately enables public results.

The Android source app uses the same API. On the Android emulator, the default backend URL is `http://10.0.2.2:8000/`. For a physical device, enter the reachable server URL provided by the administrator. Do not connect to unknown servers or share passwords.
